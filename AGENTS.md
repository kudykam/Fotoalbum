# Pokyny pro AI agenty

- Před každou prací si přečti [docs/SPECIFIKACE.md](docs/SPECIFIKACE.md). Změnu požadavku nejprve zapiš do specifikace.
- **Repozitář je veřejný.** Nikdy necommituj API klíče, tokeny, hesla, `.env` soubory ani soukromé fotografie. Konfigurace jen jako `*.example.json` bez hodnot.
- Originální fotografie se nesmí nevratně měnit ani mazat; mazání jen do koše Windows po potvrzení.
- Uživatel je senior: velké ovládací prvky, minimum dialogů, vše vratné.
